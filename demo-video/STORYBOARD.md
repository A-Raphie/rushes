## Demo Script: Rushes
**Challenge:** Pinetree Research · Solari ($300K SWE challenge)
**Time limit:** 0:60 (X post budget)
**Judging:** genuine use 40%, Solari centrality 30%, execution 20%, tech 10%

**Setup:** stage Chrome window 1280x800 on wallpaper, human cursor overlay,
product at https://tryrushes.vercel.app, no wallet flows.

### Scene 1: Hook (0:00–0:08)
**Criterion:** genuine use
**Show:** landing hero, "Your agent did the work. Here is the tape.", amber
"Point it at a task" CTA
**Say:** "An agent just finished a job on the web. Prove it actually
happened. Most demos can't. This is Rushes: every agent run leaves a
receipt you can audit."
**Action:** hold on hero, slight push-in

### Scene 2: The bench (0:08–0:20)
**Criterion:** Solari centrality + execution
**Show:** scroll to the cutting bench: the latest verified run playing in
the player, slate with serial, ink stamp, frame strip
**Say:** "This is not a screenshot. It's the actual recording of a Solari
cloud browser doing the job, committed to a public repo. The slate carries
the serial. The verdict is stamped. And it plays."
**Action:** let the tape play, scrub the frame strip once

### Scene 3: Point it at a task (0:20–0:32)
**Criterion:** genuine use
**Show:** /point composer, typing the task: name, a page, the phrase that
should be on it
**Say:** "Point it at anything. Name the task, give it up to five pages,
and the words that should be on them."
**Action:** type task name, page URL, expected phrase

### Scene 4: The run commits itself (0:32–0:44)
**Criterion:** Solari centrality + tech
**Show:** submit, the running state, then the fresh receipt: new serial,
verdict stamp, manifest
**Say:** "One click. GitHub Actions runs the recorded engine on Solari, and
the receipt writes itself: every step, every timing, the cost in credits."
**Action:** click Run it on Solari, hold on running state, land on the
fresh receipt

### Scene 5: Honest failures (0:44–0:52)
**Criterion:** genuine use + trust
**Show:** /runs registry: verified runs with tapes, failed runs with the
no-tape stamp and the reason
**Say:** "And when the infrastructure fails, the registry says so. Three
runs failed during a real replay outage, marked no tape, with the reason.
A receipts product that hides that would be a receipts product."
**Action:** slow scroll down the registry

### Scene 6: Close (0:52–1:00)
**Criterion:** all
**Show:** repo + site on screen
**Say:** "Rushes: every agent run leaves a receipt you can audit. The site,
the source, and the registry are on screen right now."
**Action:** hold on the landing with the repo URL
